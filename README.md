# CuePrompt

Browser-local teleprompter studio. No build step or application server required.

## Run locally

```sh
python3 -m http.server 5173 --directory dist
```

Open http://localhost:5173. Camera access requires localhost or HTTPS.

## Features

Script editor with local persistence, TXT import/export, templates, timed scrolling, speed and font controls, mirror, fullscreen, keyboard shortcuts, camera/microphone recording with local download. No backend, cloud sync, authentication or paid AI services.

## Search visibility

Four static HTML pages with unique titles/descriptions, self-referencing canonical URLs, internal links, JSON-LD, sitemap and robots. When moving to a custom domain, update canonical, Open Graph, structured data, robots and sitemap URLs together, then submit the sitemap through Google Search Console. The default hosted preview is owner-private and cannot be indexed until access is made public. No ranking guarantee.
